# Security policy

This repository holds data, specs and Python tools; it ships no package. A security problem here
is most likely in a workflow (`.github/workflows/`) or in data that every port vendors.

## Reporting a vulnerability

Report privately through
[GitHub security advisories](https://github.com/sanamhub/nepdate/security/advisories/new).
Don't open a public issue. Expect a first reply within a week.

Say which file or workflow is affected and how to reproduce it. A problem in one port's code goes
to that port's repository (`sanamhub/nepdate-<language>`), through its own security advisories.

A wrong date, holiday or tithi isn't a security problem: open a "Data error" issue.
