each one is called there, and the C# original it matches. The list comes from the
[shared API inventory](https://github.com/sanamhub/nepdate/blob/main/spec/API.md) every port is
built and tested against.

A row in italics is not offered in that language, with the reason in brackets; the D numbers are
listed in [Same answer everywhere](/docs/project/conformance/). For every signature, overload and
type in one language, open its full API list from its own page, for example
[TypeScript](/docs/typescript/#reference).
