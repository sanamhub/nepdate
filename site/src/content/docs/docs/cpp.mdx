Bikram Sambat dates for C++20. The core is header-only with no dependencies, the `to_chars` and
parse paths allocate nothing, and conversion is `constexpr`, so it also runs at compile time.
`nepdate-patro` is a compiled library on top of it for tithi, public holidays and events.

:::caution[Release candidate]
This is <code>{versions.cpp}</code>, the last release on the 0.2 line.
<code>{RELEASE_VERSION}</code> is the release candidate on the 1.0 line, and the API is
stable from 1.0.
:::

## Install

C++ has no central registry, so pull the release tag with CMake `FetchContent`:

<Code
  lang="cmake"
  title="CMakeLists.txt"
  code={`include(FetchContent)
FetchContent_Declare(nepdate
    GIT_REPOSITORY https://github.com/sanamhub/nepdate-cpp.git
    GIT_TAG v${versions.cpp})
FetchContent_MakeAvailable(nepdate)
target_link_libraries(your_app PRIVATE nepdate::nepdate nepdate::patro)`}
/>

Set `NEPDATE_BUILD_PATRO` to `OFF` before `FetchContent_MakeAvailable` if you need only the core.

Each [GitHub release](https://github.com/sanamhub/nepdate-cpp/releases) also has a source archive
with `SHA256SUMS`, `SHA512SUMS` and a provenance attestation; its notes show the same
`FetchContent_Declare` with the archive URL and `URL_HASH`. Packages for
[Conan Center](https://github.com/conan-io/conan-center-index/pull/31247) and
[xmake-repo](https://github.com/xmake-io/xmake-repo/pull/11133) are submitted and waiting for
review; the vcpkg overlay port in the repository works until a registry has it.

| Compiler | Minimum, proved by CI |
|---|---|
| GCC | 12 |
| Clang | 16, with libstdc++ and with libc++ |
| Apple Clang | Xcode 16 |
| MSVC | 19.44 (Visual Studio 2022 17.14) |

## Quick start

```cpp
#include <nepdate/nepdate.hpp>

#include <iomanip>
#include <iostream>

int main() {
    const nepdate::date d = nepdate::make_date(2081, 4, 15).value();
    const auto ad = d.to_year_month_day();
    std::cout << nepdate::to_string(d) << '\n';
    std::cout << static_cast<int>(ad.year()) << '-' << std::setfill('0') << std::setw(2)
              << static_cast<unsigned>(ad.month()) << '-' << std::setw(2)
              << static_cast<unsigned>(ad.day()) << '\n';
    std::cout << nepdate::to_string(nepdate::from_gregorian(ad).value()) << '\n';
    std::cout << nepdate::to_iso_string(d) << '\n';
    std::cout << d.to_ymd_int() << '\n';
}
```

## Dates, conversion and serialization

`make_date` builds a date; `from_gregorian`, `from_sys_days` and `from_local_days` convert from
Gregorian. `to_year_month_day` and `to_sys_days` go back. `to_iso_string` and `parse` are the
canonical `YYYY-MM-DD` text form, `to_ymd_int` and `from_ymd_int` the `YYYYMMDD` form.
`to_nepali_dates` and `to_english_dates` convert a whole span in input order.

## Arithmetic and fiscal year

`add_days`, `add_months` and `add_years` return `result<date>` with `overflow::clamp` or
`overflow::spill`. `days_until` returns `other - this`; `operator-` returns a `date_diff` whose
`total_days` is `this - other`. `fiscal_year` gives the start, end, range, quarter ranges and the
`2081/82` label.

```cpp
const nepdate::date d = nepdate::make_date(2081, 4, 32).value();
const auto clamped = d.add_months(2, nepdate::overflow::clamp);
const auto spilled = d.add_months(2, nepdate::overflow::spill);
const nepdate::fiscal_year fy = nepdate::fiscal_year::of(d);
```

## Formatting

`to_chars`, `to_chars_iso`, `to_chars_short`, `to_chars_long` and `to_chars_pattern` write into the
caller's buffer and allocate nothing. The `to_string` twins return `std::string`.
`std::formatter<nepdate::date>` prints `{}` as `YYYY/MM/DD` and `{:<pattern>}` through the shared
pattern language where the standard library has `<format>`. A trailing backslash in a pattern
writes a literal backslash.

```cpp
const std::string plain = nepdate::to_string(d);
const std::string nepali = nepdate::format_short(
    d, {nepdate::date_order::dmy, nepdate::separator::dash, true}, nepdate::lang::ne);
const std::string long_form = nepdate::format_long(d, {.weekday = true}, nepdate::lang::en);
```

## Parsing

`parse` reads strict `year month day` text; `parse_lenient` accepts human input such as
`2081 Shrawan 15`. Both are `constexpr` over `std::string_view` and reject rather than guess.
`try_parse` and `try_parse_lenient` return `std::optional<date>`.

```cpp
#include <nepdate/nepdate.hpp>

#include <iostream>

int main() {
    const nepdate::result<nepdate::date> strict = nepdate::parse("2081/04/15");
    const nepdate::result<nepdate::date> lenient = nepdate::parse_lenient("2081 Shrawan 15");
    std::cout << nepdate::to_string(strict.value()) << '\n';
    std::cout << nepdate::to_string(lenient.value()) << '\n';
}
```

## Ranges

`date_range` is an inclusive, non-empty view. It has the factories, containment, overlap,
adjacency, intersection, union, difference, the month and fiscal-quarter splits, the interval and
working-day views, and both string forms. The set operations return a value, `std::optional` or the
fixed `range_set`; the two splits return a `std::vector`. `std::formatter<date_range>` and
`operator<<` are available.

```cpp
const nepdate::date_range week =
    nepdate::date_range::make(nepdate::make_date(2081, 4, 10).value(),
                              nepdate::make_date(2081, 4, 16).value())
        .value();
for (const nepdate::date d : week.working_days(true)) {
    // the working days
}
const auto overlap =
    week.intersect(nepdate::date_range::of_month(2081, nepdate::month::shrawan).value());
const auto rest =
    week.subtract(nepdate::date_range::single(nepdate::make_date(2081, 4, 12).value()));
```

## Errors and result

Every fallible function returns `result<T>`, which holds a value or a `nepdate::errc`. `try_parse`
returns `std::optional` when there is no error kind to report. `errc` converts to
`std::error_code`, `make_error_condition` makes a condition, and `value()` on an error throws
`nepdate::bad_result_access`.

```cpp
const nepdate::result<nepdate::date> parsed = nepdate::parse("2081/04/33");
if (!parsed) {
    const std::error_code code = parsed.error();
}
```

## Tithi, holidays and events

```cpp
#include <nepdate/patro.hpp>

#include <iostream>

int main() {
    const nepdate::date d = nepdate::make_date(2081, 4, 15).value();
    const nepdate::patro::day_info day = nepdate::patro::info(d);
    if (const auto t = day.tithi()) {
        std::cout << t->name(nepdate::lang::en) << '\n';
    }
    std::cout << "holiday: " << (day.is_public_holiday() ? 1 : 0) << '\n';
    for (const nepdate::patro::event e : day.events()) {
        std::cout << e.name(nepdate::lang::en) << '\n';
    }
}
```

`nepdate::patro::info` returns an empty `day_info` outside BS 2077-01-01 to 2084-08-20.
