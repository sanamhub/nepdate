## Reading the numbers

- **Compare within a row of the first table, not across languages.** Each language was measured on
  its own runtime, and Swift on GitHub's macOS runner (Apple M1), not the laptop the others used
  (Intel Core i5-12500H).
- **Some runs were not on a quiet machine.** Each report records the CPU load during its run; the
  stable release repeats them on an idle machine, pinned to one core, as the spec asks.
- **Speed is not the reason to pick a date library; correct dates are.** Every port is checked
  against the same 20,360 golden rows and 7,176 month boundaries first
  ([Same answer everywhere](/docs/project/conformance/)), and the benchmarks run only after that.
