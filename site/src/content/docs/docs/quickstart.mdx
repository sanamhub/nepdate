import { Code, Tabs, TabItem } from "@astrojs/starlight/components";
import { ports } from "../../../data/ports";

Pick your language. The tab you choose here is remembered on every page with the same tabs.

## 1. Install the core

<Tabs syncKey="lang">
  {ports.map((port) => (
    <TabItem label={port.name}>
      <Code lang={port.installLang} code={port.install} />
    </TabItem>
  ))}
</Tabs>

The core has no dependencies and no almanac data. Add the patro package later if you need tithi,
holidays or events ([Core and patro](/docs/concepts/core-and-patro/)). C# NepDate is one package
with both.

## 2. Convert a date

Each snippet turns BS 2081-04-15 into AD 2024-07-30 and writes it the long way, `Shrawan 15, 2081`.

<Tabs syncKey="lang">
  {ports.map((port) => (
    <TabItem label={port.name}>
      <Code lang={port.lang} code={port.sample} />
    </TabItem>
  ))}
</Tabs>
